# HUFPEI at ACCV 2026

Static website for the **International Workshop on Human Understanding, Future Prediction, and Embodied Intelligence (HUFPEI)**.

## Repository layout

- `index.html`: home page, scope, call for papers, invited speakers, and organizers
- `registration/index.html`: registration and paper timeline
- `program/index.html`: tentative workshop program
- `assets/`: banner, portraits, favicon, and CSS
- `.nojekyll`: tells GitHub Pages to serve the files directly without Jekyll processing

## Publish with GitHub Pages

1. Copy all files and directories in this package to the root of `hufpei-workshop/accv2026`.
2. Commit and push to the repository's default branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then save.
6. The site will be published at `https://hufpei-workshop.github.io/accv2026/`.

## Items intentionally left as announcements

The source document does not provide the registration URL or detailed submission instructions. The relevant pages therefore say that these details will be announced. Search for `will be announced` to update those lines later.
